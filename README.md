A neural-network framework built step by step in NumPy for FAU's Deep Learning course. Implementations cover fully connected and convolutional layers, pooling, backpropagation, SGD, Momentum, and Adam, alongside regularization, batch normalization, RNNs, and LSTMs. Includes unit tests and a LeNet training exercise on MNIST.

`Python` `NumPy` `CNN` `RNN` `LSTM` `Backpropagation`

`Python` `Data Mining` `Classification` `Clustering` `pytest`
